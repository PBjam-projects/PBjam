Dimensionality reduction
========================

The :mod:`pbjam.DR` module constructs local, PCA-based priors from the PBjam
prior sample. It selects neighbouring stars using the supplied observables,
fits a weighted principal-component representation and transforms between the
physical and latent parameter spaces.
